# SupportRouter

SupportRouter is an end-to-end NLP project that classifies banking-support messages into
77 intents and sends low-confidence predictions to a human agent. It is designed to teach
Transformers twice: first by training a compact encoder from scratch in PyTorch, then by
fine-tuning DistilBERT with the same data, metrics, and evaluation workflow.

Examples of Banking77 intents include `card_arrival`, `declined_cash_withdrawal`,
`wrong_exchange_rate_for_cash_withdrawal`, `cash_withdrawal_not_recognised`,
`lost_or_stolen_card`, `beneficiary_not_allowed`, and `top_up_by_cash_or_cheque`. The complete
label list is read directly from the dataset so label IDs cannot drift from their official names.

## Why this is a portfolio project

- Builds a word tokenizer and encoder-only Transformer using native PyTorch.
- Fine-tunes a pretrained DistilBERT classifier with an explicit training loop.
- Uses a deterministic, stratified validation split while preserving the official test set.
- Reports accuracy, top-3 accuracy, macro precision/recall/F1, per-class results, a confusion
  matrix, and expected calibration error.
- Implements confidence-aware inference: uncertain messages are flagged for human review.
- Saves reproducible experiment metadata, best checkpoints, plots, and reports.

## Setup

Open PowerShell in this directory:

```powershell
cd C:\src\DeepLearning\projects\support-router
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

For an NVIDIA GPU, install the CUDA build of PyTorch using the command generated by the
[official PyTorch installer](https://pytorch.org/get-started/locally/). Then install this
project and the notebook tools:

```powershell
python -m pip install -e ".[notebook]"
```

Verify what PyTorch can see:

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

The first training run downloads Banking77. A DistilBERT run also downloads pretrained model
weights. Hugging Face caches both outside this repository by default.

## Recommended learning path

1. Run `notebooks/00_transformer_basics.ipynb` cell by cell.
2. Read `references/ATTENTION_EXPLAINED.md` alongside `src/support_router/models.py`.
3. Explore the real messages in `notebooks/01_explore_banking77.ipynb`.
4. Train the scratch model and inspect its errors.
5. Fine-tune DistilBERT and compare accuracy, speed, and parameter count.

The detailed sequence is in [LEARNING_GUIDE.md](LEARNING_GUIDE.md).

## Train the Transformer from scratch

From the project directory:

```powershell
support-router train --model scratch --output-dir outputs/scratch
```

The defaults use a two-layer, four-head Transformer (`d_model=128`) for up to 20 epochs with
early stopping. `--device auto` chooses CUDA when PyTorch reports it as available and prints
the selected GPU before training.

For a quick end-to-end check:

```powershell
support-router train --model scratch --epochs 1 --output-dir outputs/smoke
```

## Fine-tune DistilBERT

```powershell
support-router train --model distilbert --output-dir outputs/distilbert
```

This uses `distilbert/distilbert-base-uncased`, a batch size of 16, a learning rate of `2e-5`,
and four epochs by default. Reduce `--batch-size` if GPU memory is insufficient.

## Evaluate and predict

Re-evaluate the official Banking77 test split:

```powershell
support-router evaluate --experiment-dir outputs/scratch
```

Classify one or more support requests:

```powershell
support-router predict --experiment-dir outputs/scratch "my cash withdrawal is missing"
support-router predict --experiment-dir outputs/distilbert "I do not recognize this transfer" "where is my new card"
```

The JSON response contains the predicted intent, confidence, top alternatives, and
`route_to_human`. The flag becomes `true` below the experiment's confidence threshold
(default `0.65`):

```powershell
support-router predict --experiment-dir outputs/distilbert --confidence-threshold 0.75 "please help"
```

## Experiment artifacts

Each output directory contains:

- `experiment.json`: model type, labels, dataset, seed, split, and architecture settings;
- `history.json` and `learning_curves.png`: epoch-by-epoch results;
- `best.pt` plus `tokenizer.json` for the scratch model, or `best_model/` for DistilBERT;
- `test_metrics.json`, `test_report.md`, and `confusion_matrix.png`.

Generated outputs and model weights are ignored by Git. Training starts a new experiment; it
does not currently resume an interrupted optimizer state.

## Data and responsible-use notes

Banking77 is released under CC BY 4.0. Review the
[dataset card](https://huggingface.co/datasets/PolyAI/banking77) for its source and license.
This project is educational: an intent classifier can misroute ambiguous or out-of-distribution
requests. Confidence thresholding helps, but production deployment would also require privacy
review, monitoring, drift detection, representative evaluation, and a reliable human fallback.
