# TerraClass

TerraClass is a learning-focused PyTorch project that classifies satellite images into 10 land-use and land-cover categories. It uses the RGB version of [EuroSAT](https://github.com/phelber/EuroSAT), a dataset of 27,000 labeled Sentinel-2 image patches.

The project deliberately includes two approaches:

- `cnn`: a compact convolutional neural network written from scratch, for learning PyTorch fundamentals.
- `resnet18`: an ImageNet-pretrained model, for learning transfer learning and building a stronger practical baseline.

Both models use the same reproducible data splits, training loop, metrics, checkpoint format, and inference workflow, making the comparison fair and easy to understand.

## What you will learn

By working through this project, you will use:

- tensors and accelerator devices;
- `Dataset`, `DataLoader`, transforms, and data augmentation;
- models built with `torch.nn.Module`;
- forward passes, cross-entropy loss, autograd, and optimizers;
- training, validation, and held-out test splits;
- checkpointing, early stopping, and learning-rate scheduling;
- accuracy, macro F1, per-class metrics, and confusion matrices;
- transfer learning with ResNet18;
- inference and Grad-CAM model explanations.

Read [LEARNING_GUIDE.md](LEARNING_GUIDE.md) alongside the source code for a guided tour.

For layer shapes, parameter-count formulas, training-memory implications, and the exact SimpleCNN/ResNet18 totals, see [references/MODEL_ARCHITECTURE.md](references/MODEL_ARCHITECTURE.md).

## Dataset

EuroSAT contains the following classes:

`AnnualCrop`, `Forest`, `HerbaceousVegetation`, `Highway`, `Industrial`, `Pasture`, `PermanentCrop`, `Residential`, `River`, and `SeaLake`.

TorchVision downloads the dataset automatically the first time training or evaluation runs. TerraClass creates a deterministic, stratified 70/15/15 train/validation/test split so every class is represented proportionally.

## Quick start

From this directory, create and activate a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

On macOS or Linux, activation is `source .venv/bin/activate` instead.

Install the project in editable mode:

```powershell
python -m pip install --upgrade pip
python -m pip install -e .
```

To run the included notebook, install its optional environment instead:

```powershell
python -m pip install -e ".[notebook]"
```

If you have an NVIDIA GPU, use the command generated by the official [PyTorch installation selector](https://pytorch.org/get-started/locally/) before `pip install -e .` so you receive the correct CUDA build.

Confirm that the commands are available:

```powershell
terraclass --help
```

## Experiment 1: build a CNN from scratch

Start with the small model. Its 64-by-64 inputs match the native EuroSAT image size, and it is practical to train on a CPU while learning the workflow.

```powershell
terraclass train `
  --model cnn `
  --epochs 15 `
  --batch-size 64 `
  --output-dir outputs/cnn
```

For a quick pipeline check before a full run, use one epoch:

```powershell
terraclass train --model cnn --epochs 1 --output-dir outputs/smoke-test
```

## Experiment 2: fine-tune ResNet18

ResNet18 uses 224-by-224 inputs and pretrained ImageNet weights by default:

```powershell
terraclass train `
  --model resnet18 `
  --epochs 10 `
  --batch-size 32 `
  --learning-rate 0.0003 `
  --output-dir outputs/resnet18
```

To first train only the new classification layer, add `--freeze-backbone`. To run without downloading pretrained weights, add `--no-pretrained`.

## Resume an interrupted run

Every epoch updates `last.pt`. The epoch count is the desired total, not the number of additional epochs:

```powershell
terraclass train `
  --model cnn `
  --epochs 25 `
  --output-dir outputs/cnn `
  --resume outputs/cnn/last.pt
```

Use the same model, image size, and split settings when resuming.

## Evaluate a trained model

The training command automatically evaluates the best validation checkpoint on the test set. You can repeat evaluation separately:

```powershell
terraclass evaluate outputs/cnn/best.pt `
  --output-dir outputs/cnn-evaluation
```

The report includes overall accuracy, macro precision/recall/F1, support and metrics for every class, and the complete confusion matrix.

## Predict and explain an image

Classify a JPEG or PNG and show the three most likely classes:

```powershell
terraclass predict outputs/cnn/best.pt path/to/satellite-image.jpg
```

Save a Grad-CAM overlay to inspect which regions influenced the top prediction:

```powershell
terraclass predict outputs/cnn/best.pt path/to/satellite-image.jpg `
  --gradcam-output outputs/explanations/example.png
```

Grad-CAM is a diagnostic tool, not proof that a model has learned the right causal features.

## Generated artifacts

Each training run creates:

```text
outputs/experiment/
├── best.pt                 # checkpoint with the best validation macro F1
├── last.pt                 # latest checkpoint, used to resume training
├── metrics.json            # epoch history and final test report
├── history.png             # loss and macro-F1 learning curves
└── confusion_matrix.png    # test predictions broken down by class
```

These files are intentionally ignored by Git. Record final results in this README rather than committing large checkpoints.

## Reproducibility and limitations

- Python, NumPy, and PyTorch are seeded, and the split is deterministic for a given seed. Exact GPU results can still vary because some accelerator operations are nondeterministic.
- The packaged RGB dataset contains less spectral information than the original 13-band Sentinel-2 imagery.
- A stratified random split measures performance on similar EuroSAT tiles. Spatially separated evaluation would be a stronger test of generalization, but geographic metadata is not exposed by the packaged RGB dataset.
- Predictions describe the visual class learned from EuroSAT; they should not be used directly for environmental, legal, or planning decisions.
